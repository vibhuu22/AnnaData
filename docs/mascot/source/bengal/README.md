# Bengal Ankur poses

The founder's Gemini renders (2000 × 2000, plain white background), 20 November 2026,
made from the pose kit: the Bengal look plus Master Ankur's pose references.

Rebuild the app pictures from the repository root:

    python AnnaData-Frontend-main/tools/prepare_ankur_look.py bengal docs/mascot/source/bengal


`idle.mp4` is the founder's green-screen Gemini clip (10 s, last frame = first,
so it loops seamlessly). Rebuild Bengal's idle animation with:

    python AnnaData-Frontend-main/tools/prepare_ankur_idle.py bengal docs/mascot/source/bengal/idle.mp4
